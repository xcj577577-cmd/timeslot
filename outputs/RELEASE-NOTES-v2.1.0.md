# 时隙 2.1.0（Build 50）

发布日期：2026 年 8 月 9 日

## 桌面小组件恢复与升级

- 恢复小组件扩展被误删的 App Sandbox 与 App Group 授权，修复扩展启动崩溃和小组件消失。
- 保留并验证原有共享数据，不需要重新建立倒计时或专注历史。
- 新增组合、倒计时、正计时、番茄钟、本周目标及可配置小组件。
- 重新设计小、中、大尺寸布局、品牌背景、状态标识与进度表现。
- 使用系统实时计时文本和关键时间点时间线，减少无意义刷新并提升走时稳定性。
- 点击小组件可回到对应页面；修复隐藏应用时点击小组件会重复创建主窗口的问题。

## 视觉与交互

- 建立统一的颜色、字体、间距、圆角与表面层级设计系统。
- 重设计侧栏、倒计时详情、搜索、空状态、编辑器、设置与小组件指南。
- 倒计时编辑器新增快捷日期、命名配色、输入校验与实时预览。
- 更新 v3 品牌标识、横向标识、营销 PNG、SVG 与完整 AppIcon 集合。
- 完善深色模式、最小窗口、键盘导航、辅助功能标签与减少动态效果支持。

## 稳定性与数据安全

- 修复用户主动清空倒计时后，重启应用又自动恢复样例的问题。
- 修复删除、导入或重启后残留的倒计时通知，并避免异步通知调度竞争。
- 修复异常 Pomodoro 状态、双计时并行、非法颜色和不可信字段。
- 共享状态改为原子写入并限制小组件历史数据量。
- 备份新增格式版本、旧格式兼容、大小/条目限制与严格校验。
- 导入前必须成功创建本地自动备份；失败时不改动当前数据。
- 新增小组件同步健康状态与手动刷新入口。

## 隐私与发行质量

- 主应用与小组件新增 Privacy Manifest。
- 两个目标均启用 App Sandbox、共享同一 App Group，且不含网络客户端权限。
- 版本升级为 2.1.0（Build 50），支持 macOS 14+、Apple Silicon 与 Intel。
- 核心测试扩充到 29 项，并新增一键 Release 发行校验脚本。

## 已验证

- 29 项自动化测试通过。
- Release 双架构构建、深度严格签名、授权、隐私清单和版本校验通过。
- macOS 小组件库能显示全部时隙类型及三种尺寸预览。
- 实际桌面倒计时小组件已添加、渲染并验证点击跳转。

正式公开分发仍需使用 Developer ID 或 App Store Distribution 证书，并完成 Apple 公证或 App Store 审核。
