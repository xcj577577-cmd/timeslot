# 时隙 2.2.0 产品化与发行验证报告

核验日期：2026 年 8 月 13 日

## 本轮交付

- 修复深色模式切回浅色后侧栏外观不同步的问题，并统一系统设置与应用内设置入口。
- 清理重复顶层“帮助”菜单，保留原生帮助菜单并加入小组件说明入口。
- 为“时隙 · 自定义”小组件增加动态倒计时目标参数；多个组件可分别绑定不同目标。
- 保留旧配置兼容：没有目标 UUID 时回退到当前固定倒计时；静态“时隙 · 倒计时”继续使用简单固定模式。
- 增加通知权限状态、删除倒计时/清空历史后的 8 秒撤销恢复。
- 将番茄钟专注与统计拆分为独立工作区。
- 增加本地存储 v2 迁移契约：升级前保存旧版键值快照，规范化和原子小组件写入完成后才标记成功。
- 版本统一为 2.2.0（Build 52），更新发布资料、使用说明、检查清单、更新日志和交付包。

## 数据恢复记录

安装前只读核对发现当前共享容器中的 `countdownItems` 已是合法空数组，不能由新版本自动推断出原目标。此前保留的 2.1.1 安装前 App Group 快照包含一条用户倒计时，因此仅通过官方应用界面恢复了这一条：

- 标题：示例目标
- 目标：未来日期 00:00（北京时间）
- 颜色：青绿
- 未覆盖番茄钟状态、已有专注历史或正计时状态

当前数据仍保存在原 App Group。本机回滚资料不纳入公开仓库。

## GitHub-only 发布边界

本轮发布渠道确定为 GitHub：源码进入仓库，版本化 ZIP/DMG 与 SHA-256 校验文件作为 GitHub Release 附件；不走 Mac App Store 上架流程。

当前发行包使用本机 Apple Development 签名，尚未完成 Apple 公证。它可以作为 GitHub Release 候选包，但陌生设备首次打开时可能出现 macOS 安全提示。不得通过移除隔离属性绕过 Gatekeeper；若后续面向大量陌生设备分发，应改用 Developer ID 签名并完成公证。
