# 时隙 隐私政策

生效日期：2026 年 8 月 9 日

## 概述

时隙是一款运行在 macOS 上的本地生产力工具，提供倒计时、番茄钟、正计时、专注记录和桌面小组件。

**时隙不收集、不上传、不出售个人信息，也不使用广告或跨应用追踪。**

## 数据收集

时隙不收集以下数据：

- 姓名、邮箱、手机号或其他身份信息
- 使用分析、广告标识符或营销画像
- 由开发者接收的崩溃日志或诊断数据
- 位置、通讯录、照片、麦克风或摄像头数据

应用不要求账号，不包含第三方广告、分析或追踪 SDK。

## 本机存储

倒计时、番茄钟记录、任务、偏好设置和小组件状态只保存在你的 Mac 上，主要位于：

- 应用沙盒容器：`~/Library/Containers/com.xianz.countdownwidget/`
- App Group 共享容器：`~/Library/Group Containers/4FKFDX48HX.com.xianz.countdownwidget.shared/`

App Group 仅供时隙主应用与其 WidgetKit 扩展在本机共享状态。主应用和扩展均未声明 App Sandbox 网络客户端权限。

## 通知

倒计时完成或番茄钟阶段结束时，时隙可通过 macOS 发送本地通知。通知内容在本机生成，不会由时隙发送到开发者服务器。你可以在时隙设置或“系统设置 → 通知”中关闭权限。

## 备份与导入

“导出备份”会将数据写入你选择的本地 JSON 文件。导入时，时隙会先在本机创建当前数据的安全备份；如果备份失败，导入不会覆盖现有数据。备份文件由你自行保管，时隙不会自动上传到云端。

如果你把备份文件主动保存到 iCloud Drive、第三方同步文件夹或其他外部位置，该位置的隐私与保留规则由相应服务提供方负责。

## 删除数据

从“应用程序”中删除 `时隙.app` 不保证 macOS 同时移除 App Group 数据。若要彻底删除：

1. 退出时隙。
2. 如需保留记录，先导出备份。
3. 删除 `时隙.app`。
4. 在 Finder 中选择“前往 → 前往文件夹”，分别打开并删除上述两个容器目录。

删除容器后无法在应用内恢复，除非你仍持有之前导出的备份。时隙没有服务器端副本。

## 儿童隐私

时隙不面向任何年龄段收集个人信息，也没有账号、广告或行为画像。

## 政策更新

如果功能或数据处理方式发生实质变化，我们会更新本政策的生效日期，并在版本说明中说明。任何新增网络或数据收集能力都需要重新披露并更新 App Store 隐私信息。

## 联系方式

公开 HTTPS 页面与支持邮箱尚未提供。当前以本仓库中的此文件为 2.2.0 政策正文；问题可通过 GitHub Issues 反馈。
