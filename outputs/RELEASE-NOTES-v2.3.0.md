# 时隙 2.3.0（Build 53）

## 这次更新

- 全新 graphite 视觉系统：深色石墨配色与更克制的层级信号，全面重绘首页、倒计时与专注工作区。
- 首页重排为「下一目标 + 当前专注」双卡片，配合时间轴与工作读数，一眼看到最关键的目标与节奏。
- 统一看板结构：倒计时、番茄钟与正计时共用一致的版式与操作路径。
- 新增专注洞察与历史记录编辑，可修正过去记录的起止时间与任务归属。
- 时间轴交互重做：修复并回归捏合缩放，滚动与平移更顺滑。
- 性能优化：分级刷新节奏、清理空闲计时器，降低常驻功耗。
- README 与使用说明的截图、界面说明同步新版界面。

## 兼容与隐私

- 继续支持 macOS 14+、Apple Silicon 与 Intel Mac。
- 不需要登录，不增加网络权限；数据仍保存在本机 App Sandbox 与 App Group 中。
- 旧版倒计时、专注记录与小组件共享状态保持兼容。
