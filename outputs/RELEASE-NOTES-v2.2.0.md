# 时隙 2.2.0（Build 52）

## 这次更新

- 新增可配置小组件的独立倒计时目标：多个“时隙 · 自定义”小组件可分别绑定不同倒计时。
- 保留静态“时隙 · 倒计时”的简单模式，旧小组件配置继续自动回退到当前固定目标。
- 新增本地存储 v2 迁移契约：升级前保留旧版迁移快照，规范化完成后才标记迁移成功。
- 设置页显示通知权限、共享同步与本地数据迁移状态。
- 删除倒计时、清空阶段记录后增加 8 秒撤销恢复。
- 番茄钟的专注与统计拆分为独立工作区，降低信息拥挤并提升查阅效率。
- 修复深色模式切回浅色后的侧栏外观同步问题，统一设置入口并清理重复帮助菜单。
- 增加稳定的 UI 冒烟流程与 31 项核心逻辑测试，完善双架构发行校验。

## 兼容与隐私

- 继续支持 macOS 14+、Apple Silicon 与 Intel Mac。
- 不需要登录，不增加网络权限；数据仍保存在本机 App Sandbox 与 App Group 中。
- 旧版倒计时、番茄钟、历史记录和小组件共享状态保持兼容。
