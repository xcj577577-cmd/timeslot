## 三、正式对外分发（上架/公测前必须）

- [ ] 申请 Developer ID Application 证书（Xcode → Settings → Accounts → Manage Certificates）
- [ ] 用 Developer ID 重新签名：codesign --force --options runtime --deep --sign "Developer ID Application: ..." 时隙.app
- [ ] 公证：xcrun notarytool submit 时隙-macOS.dmg --apple-id "你的Apple ID" --team-id "4FKFDX48HX" --password "app-specific-password" --wait
- [ ] 公证通过后 stapler：xcrun stapler staple 时隙-macOS.dmg
- [ ] 在干净系统上双击 DMG 安装，确认无“未知开发者”拦截
- [ ] 如果走 App Store：App Store Connect 创建应用、上传归档，隐私标签填“Data Not Collected”
