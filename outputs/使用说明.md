# 时隙 2.0.0

“时隙”包含倒计时和番茄钟，以及真正的 macOS WidgetKit 桌面小组件。它和天气、日历小组件一样位于桌面层，不是悬浮窗口，也不会盖住普通应用。

所有日期边界、历史筛选和日期显示均按北京时间（Asia/Shanghai，UTC+8）计算。

## 2.0.0 更新

- 上市版字体系统：全界面改用圆体系统字体，中文标题不再生硬拉大字距，正文与说明文字统一行距，计时数字统一半粗圆体 + 等宽数字，走秒不再抖动。
- 卡片体系全面统一：主卡、侧栏卡、嵌套块全部使用同一套浅色底、细描边、柔和阴影，视觉更干净、更精致。
- 新增键盘导航：⌘1 切到倒计时、⌘2 切到番茄钟、⌘N 新建倒计时、空格 开始/暂停番茄钟。
- 微动效：计时进行中图标呼吸提示，进度圆环平滑推进，停止/暂停按钮有弹性反馈。
- 桌面小组件同步升级：标题字体圆润、字距更克制，背景加入品牌色极浅渐变，与 App 视觉语言一致。
 - 倒计时完成通知：到达目标时间后，应用会通过系统通知提醒并响铃（需在首次提示时允许通知）；通知按北京时间精确触发，暂停、修改或删除倒计时后会自动同步更新。
 - 点击桌面小组件直接打开应用：倒计时小组件打开「倒计时」页，番茄钟小组件打开「番茄钟」页。
 - 新增「关于时隙」面板（菜单栏 → 时隙 → 关于时隙），展示 v3 标识、版本与简介。
 - 版本号升级为 2.0.0（Build 48），品牌标识沿用 v3：深海蓝到青绿渐变底上，左右两条青绿时间条带错位排布，中央露出金色斜切“时隙”。

## 添加到 Mac 桌面

1. 打开“时隙”，新建或选择一个倒计时。
2. 在应用里选择要在桌面显示的内容（可选，默认自动跟随）。
3. 在桌面空白处右键，选择“编辑小组件”。
4. 搜索“时隙”或“时隙桌面小组件”。如果要在组件菜单中直接选择显示内容，新增“时隙桌面小组件（可编辑）”。
5. 选择小号或中号样式，点击或拖到桌面。

添加后可像天气、日历一样在桌面上长期保留。要移动或移除时，在桌面进入“编辑小组件”即可。

“时隙桌面小组件（可编辑）”支持右键“编辑小组件”，可选择“跟随时隙”“番茄钟”或“倒计时”。选择“跟随时隙”时，它自动沿用应用里选中的内容；选择“番茄钟”或“倒计时”时，可固定显示对应类型。

## 使用番茄钟

1. 打开“时隙”，在左侧选择“番茄钟”。
2. 输入本轮要专注的任务，点击“开始”。
3. 可随时暂停、停止并记录、重置或跳过当前阶段。
4. 点击“设置”可调整专注、短休息、长休息时长及轮次。
5. 番茄钟开始、暂停、停止或切换任务后，桌面小组件会自动跟随，不需要手动同步。

番茄钟卡片顶部可以在「番茄钟 / 正计时」之间切换：

- 番茄钟：按设定的专注、短休息、长休息时长倒计时，阶段自动流转。
- 正计时：不设时长，从零开始累计；点击「停止」会把本次用时按当前任务记入阶段记录，并计入专注统计；「重置」不会保留本次时长。

在“当前任务”中可以选择已保存的番茄任务，点击“管理任务”可添加或删除任务。每条阶段记录都会保留当时的任务名称，桌面小组件也会显示当前任务。为避免时长被归入错误任务，阶段开始后会锁定任务选择；请先“停止并记录”，再切换到下一个任务。

每个阶段结束、跳过或重置后，实际用时会保存到“阶段记录”中，并按专注、短休息、长休息分别累计统计。暂停后继续会合并为同一个阶段记录。你可以在“查看时间范围”中选择全部、今天、近 7 天、本月，或自定义起止日期，查看某段时间内的专注时长。

“专注趋势”会把所选范围内的实际专注时长按天绘制成柱状图，并同时显示累计时长、专注日均和单日最高时长。切换日期范围时，图表和汇总会一起更新；跨午夜的专注记录会按实际比例计入对应日期。

番茄钟使用统一的系统时钟；Mac 唤醒或应用从后台恢复后，显示时间不会超过设置的阶段时长。

点击“停止并记录”会立即结束当前阶段，并把已经进行的实际用时写入记录；专注阶段的这段时间会计入所选日期范围的“专注总计”。开始、暂停、停止、重置、跳过和阶段切换都会自动刷新桌面小组件。

桌面小组件在每次操作后会立即请求刷新，同时每 60 秒自行读取最新状态作为兜底；即使系统暂时合并了刷新请求，小组件也会自动跟上，不再需要手动同步。

## 安装包

 - 时隙-macOS.zip：解压后把 时隙.app 拖入“应用程序”文件夹。
 - 时隙-macOS.dmg：打开后将 时隙.app 拖到「Applications」图标上即可完成安装。

应用已使用开发者证书签名。正式对外分发（消除“未知开发者”提示）时，建议改用 Developer ID 证书签名并提交 Apple 公证；代码与打包流程已就绪。

## 快捷键

 - ⌘N：新建倒计时
 - ⌘1 / ⌘2：在倒计时与番茄钟之间切换
 - ⌘,：打开设置（通知、声音、备份）
 - 空格：开始 / 暂停当前计时
 - 菜单栏 → 时隙 → 关于时隙：查看版本与品牌信息

## 品牌文件

- `时隙-logo-v3-错位条带-2048.png`：主标识，方形 2048×2048。
- `时隙-logo-v3-横向-2048.png`：横向组合标识 4096×1536。
- `时隙-logo-v3.svg` / `时隙-logo-v3-横向.svg`：矢量源文件，可无限缩放。
- `logo-variants/`：v3 的备选变体（错位条带首版、缺口环、双楔），如想切换可告知。
