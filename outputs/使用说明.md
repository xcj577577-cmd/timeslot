# 时隙 2.2.0 使用说明

时隙提供首页看板、倒计时、番茄钟、正计时、专注统计与原生 macOS 桌面小组件。它不是悬浮窗，不会遮挡其他应用。所有日期边界按北京时间（Asia/Shanghai）计算。

## 安装

1. 将 `时隙.app` 放入“应用程序”文件夹。
2. 从“应用程序”中打开时隙一次，让 macOS 注册桌面小组件。
3. 如需通知，在系统提示中选择允许；拒绝不会影响计时功能。

## 恢复或添加桌面小组件

1. 打开时隙，在倒计时页选择目标。
2. 点击“更新小组件内容”。
3. 在桌面空白处右键，选择“编辑小组件”。
4. 搜索“时隙”。
5. 选择小组件类型和小、中、大尺寸，点击或拖到桌面。
6. 如果添加的是“时隙 · 自定义”，右键每个实例选择“编辑小组件”，在“倒计时目标”中分别选择目标。

可选类型包括：

- 时隙 · 自定义：右键“编辑小组件”，选择跟随应用、倒计时或番茄钟，并可为每个实例绑定不同倒计时目标。
- 时隙 · 倒计时：固定显示当前选中的目标，适合继续使用“更新小组件内容”的简单模式。
- 时隙 · 正计时：显示自由专注计时。
- 时隙 · 番茄钟：显示当前阶段与任务。
- 时隙 · 本周专注目标：显示本周累计与目标进度。
- 时隙桌面小组件：在中、大尺寸中组合展示关键信息。

应用中的状态变化会立即写入共享状态并请求 WidgetKit 刷新。进行中的倒计时、番茄钟和正计时使用系统实时文本持续走字；关键结束时间写入小组件时间线。macOS 会根据系统资源与刷新预算安排实际刷新时机。

如果小组件库暂时没有出现“时隙”，请确认应用位于“应用程序”文件夹，退出后重新打开一次，再重新进入“编辑小组件”。

## 首页看板

启动时默认进入首页看板。顶部时间轴可通过滚轮或捏合缩放，也可以左右平移查看不同日期；色块深浅表示专注时长。下方提供倒计时、番茄钟、正计时快捷卡片，以及今日分布、连续专注、时段分布、本周累计和近 7 天趋势等读数。

## 倒计时

1. 点击侧栏顶部的 `+` 或按 `⌘N`。
2. 输入标题，选择目标日期、时间与显示单位。
3. 保存后可暂停、继续、编辑或删除。
4. 选择“更新小组件内容”后，独立倒计时组件会显示该目标。

删除前会二次确认。修改、暂停或删除倒计时后，相关本地通知会同步更新或移除。

## 番茄钟与正计时

按 `⌘2` 进入番茄钟页面。

- 番茄钟：按设置的专注、短休息、长休息时长与轮次流转。
- 正计时：从零自由累计；“停止”会按当前任务写入记录，“重置”不会保存本次时长。

阶段进行中会锁定任务，避免把时长记到错误任务。需要切换任务时，先停止并记录当前阶段。番茄钟与正计时不会同时运行；切换模式时应用会保持状态一致。

## 专注记录

阶段记录支持全部、今天、按周、近 7 天、本月和自定义日期范围。右键记录可修正起止时间或任务名，时长按新的墙钟时间重算；跨午夜记录会按实际时间分配到对应日期。统计包括累计专注时长、专注日均、单日最高、按天趋势与按任务分布。

## 设置、同步与备份

按 `⌘,` 打开设置，可管理通知、提示音、跟随系统/浅色/深色外观、番茄节奏、备份与小组件同步状态。版本升级时，时隙会先在 `~/Library/Application Support/时隙/Migrations/` 保留迁移快照，再整理本地数据；设置页会显示迁移状态。

导出备份会生成本地 JSON 文件，包含倒计时、阶段记录、任务和显示设置。导入会覆盖当前数据，但时隙必须先成功创建当前数据的自动备份；自动备份失败时，导入会中止且不会修改现有数据。

建议在系统升级、换机或批量修改数据前手动导出一次备份。

## 快捷键

- `⌘N`：新建倒计时
- `⌘F`：搜索倒计时
- `⌘1`：倒计时页面
- `⌘2`：番茄钟页面
- `⌘,`：设置
- `空格`：开始或暂停当前计时

## 数据与删除

时隙不联网、不要求账号。数据保存在应用沙盒与 App Group 共享容器中。仅把应用拖到废纸篓不一定会删除容器数据；如需彻底清除，请先导出要保留的备份，再按 `outputs/隐私政策.md` 中的步骤删除本地容器。

## 系统要求与分发说明

- macOS 14 Sonoma 或更新版本
- Apple Silicon 或 Intel Mac

本项目仅通过 GitHub 发布源码与版本化 ZIP/DMG。当前包使用 Apple Development 证书签名、尚未完成 Apple 公证；首次下载后 macOS 可能显示安全提示。面向大量陌生设备正式分发时，应改用 Developer ID 签名并完成公证；不要通过移除隔离属性绕过 Gatekeeper。
