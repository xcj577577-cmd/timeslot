# 时隙

把重要目标与专注节奏固定在 Mac 桌面。

时隙是一款原生 macOS 倒计时与专注工具。桌面内容由 WidgetKit 提供，和天气、日历一样驻留在桌面层；所有日期边界按北京时间（Asia/Shanghai）计算。

## 主要功能

- **倒计时**：新建、编辑、暂停与继续任意目标，到时发送本地通知。
- **番茄钟**：专注、短休息、长休息自动流转，可调整时长与轮次。
- **正计时**：自由累计专注时长，停止后按任务写入统计。
- **专注记录**：按日期与任务查看趋势、总时长、日均和单日最高。
- **桌面小组件**：提供组合、可配置倒计时、正计时、番茄钟和本周目标等独立样式，支持小、中、大尺寸；每个可配置小组件可绑定不同倒计时。
- **本地备份**：导出或导入 JSON；导入前必须先成功创建当前数据的自动备份。
- **安全升级**：本地存储保留版本标记；首次升级先保存旧版迁移快照，再规范化数据，不依赖数据库也不影响桌面小组件共享。
- **无账号、无广告、无网络权限**：数据仅保存在 App Sandbox 与 App Group 中。

应用中的状态变化会写入共享状态并请求 WidgetKit 刷新。运行中的计时数字使用系统实时文本，关键结束时间写入时间线；实际刷新调度仍由 macOS 管理。

## 快捷键

- `⌘1`：倒计时
- `⌘2`：番茄钟
- `⌘N`：新建倒计时
- `⌘F`：搜索倒计时
- `⌘,`：设置
- `空格`：开始或暂停当前计时

## 系统要求

- macOS 14 Sonoma 或更新版本
- Apple Silicon 或 Intel Mac（通用二进制）

## 构建与验证

```bash
# 核心逻辑测试
swift test --disable-sandbox

# Release 构建、双架构、签名、沙盒、App Group、隐私清单与版本校验
./scripts/verify-release.sh /tmp/timeslot-release
```

验证后的应用位于 `/tmp/timeslot-release/Build/Products/Release/时隙.app`。

## 安装与添加小组件

1. 将 `时隙.app` 放入 `/Applications` 并打开一次。
2. 在时隙中选择倒计时，点击“更新小组件内容”（兼容静态倒计时组件）。
3. 在桌面空白处右键，选择“编辑小组件”。
4. 搜索“时隙”，选择类型与尺寸后添加。
5. 如需多个组件显示不同目标，添加“时隙 · 自定义”，再右键每个实例选择“编辑小组件”并分别设置倒计时目标。

当前工程使用 Apple Development 证书完成本机签名验证。正式对外分发前，还需使用 Developer ID 或 App Store Distribution 签名并完成 Apple 公证/商店审核；不要通过移除隔离属性绕过 Gatekeeper。

## 目录结构

- `Sources/CountdownWidget/`：主应用界面、模型、状态、通知与备份。
- `WidgetExtension/`：WidgetKit 桌面小组件扩展。
- `Tests/`：核心逻辑测试。
- `AppBundle/`：主应用 Info.plist、授权与隐私清单。
- `scripts/`：品牌资产生成与 Release 验证脚本。
- `outputs/`：品牌资产、使用说明、隐私政策与发布资料。

## 隐私

时隙不联网、不追踪、不收集数据，也不要求账号。详见 `outputs/隐私政策.md`。
